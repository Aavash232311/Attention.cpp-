* Google collab cuda setup for python related setup


*** Installing the cuda runtime

 #+BEGIN_SRC BASH
pip install "jupyter-kernel-client==0.9.0"
 #+END_SRC

*** Selecting the GPU runtime
#+BEGIN_SRC BASH
colab new --gpu t4
#+END_SRC

*** Executing the script
#+BEGIN_SRC Python

import torch
if __name__ == "__main__":
    current_device = torch.cuda.current_device()
    print(f"GPU Model Name: {torch.cuda.get_device_name(current_device)}")i

Example:- executing script named main.py

#+BEGIN_SRC BASH
colab exec -f main.py
#+END_SRC

*** Stopping the runtime

It's important to stop the runtime not to waste the compute time

#+BEGIN_SRC Python
colab stop
#+END_SRC
