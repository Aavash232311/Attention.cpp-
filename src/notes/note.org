
* Understanding of the embeddings inside the Transformer

** Token embeddings:
Token embeddings are of shape [vocab_size, d_model]. They are randomly initialized at first and learned during the training process. We can imagine the embedding matrix as a high-dimensional vector space that contains all the vocabulary we want the model to learn from.

** Positional encoding:
Taking the original Transformer as an example, it used sinusoidal positional encoding, which was fixed during training. The position is determined by sine and cosine functions according to the position index, storing them in a higher-dimensional space.
